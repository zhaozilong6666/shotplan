## 边界

- 28 句由知识库官方名生成，验证的是「受支持的城市 / 风格不会被认错」，不是真实客户措辞的准确率；真实分布需要人工标注后再补。
- 三策略只验证不变量（不改约束、全部可执行、推荐不选失败方案），不评价哪种取舍更好；收敛是合法结论，不是缺陷。
- 协商只验证「每个建议都通过预检且改动最小」，不评价用户是否愿意接受。
